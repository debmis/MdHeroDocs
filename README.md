## About MdHero

MdHero is a desktop tool for developers and PR reviewers working with markdown documents. It opens any folder on your machine as a workspace, renders markdown in a live preview, and overlays a **block-level diff against any git ref** directly into the rendered output. That makes it especially useful for reviewing prose-heavy pull requests and seeing exactly what an AI coding agent changed.

The app is fully offline. There are no accounts, no sign-in, no telemetry, and no network requests originating from MdHero itself. Everything is processed locally.
